Docker Compose Configuration

Сервисы

PostgreSQL Database

db:
  image: postgres:14
  container_name: finance_postgres
  restart: always
  environment:
    POSTGRES_USER: postgres
    POSTGRES_PASSWORD: password
    POSTGRES_DB: weba1
  ports:
    - "5433:5432"
  volumes:
    - postgres_data:/var/lib/postgresql/data

Назначение: Основная база данных приложения
Порт: 5433 (внешний) → 5432 (внутренний)
Данные: Сохраняются в volume postgres_data

Redis

redis:
  image: redis:7
  container_name: finance_redis
  restart: always
  ports:
    - "6380:6379"

Назначение: Брокер сообщений для Celery
Порт: 6380 (внешний) → 6379 (внутренний)

Finance Application

finance:
  build: ./finance
  container_name: finance_app
  depends_on:
    - db
    - redis
  env_file: ./finance/.env
  ports:
    - "8000:8000"
  volumes:
    - ./finance:/app
  command: ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000", "--reload"]

Назначение: Основное веб-приложение
Зависимости: PostgreSQL, Redis
Порт: 8000
Режим: Development с hot reload

Parser Service

parser:
  build: ./parser
  container_name: parser_app
  depends_on:
    - db
  env_file: ./parser/task2/.env
  ports:
    - "9000:9000"
  volumes:
    - ./parser:/parser
  command: ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "9000"]

Назначение: Сервис парсинга HTML
Зависимости: PostgreSQL
Порт: 9000

Celery Worker

celery_worker:
  build: ./finance
  container_name: celery_worker
  depends_on:
    - redis
    - finance
  command: ["celery", "-A", "celery_worker", "worker", "--loglevel=info"]
  volumes:
    - ./finance:/app
  environment:
    - CELERY_BROKER=redis://redis:6379/0
    - CELERY_BACKEND=redis://redis:6379/0

Назначение: Обработчик фоновых задач
Зависимости: Redis, Finance app
Модуль: celery_worker

Volumes

volumes:
  postgres_data:

Назначение: Постоянное хранение данных PostgreSQL

Запуск системы

Development режим

docker-compose up --build

Production режим

docker-compose up -d

Остановка

docker-compose down

Просмотр логов

docker-compose logs -f
