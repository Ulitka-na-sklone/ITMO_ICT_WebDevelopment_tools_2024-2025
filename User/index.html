User Endpoints

Authentication

POST /login
Аутентификация пользователя. Возвращает JWT токен.
Тело: {username, password}

POST /registration
Регистрация нового пользователя. Возвращает JWT токен.
Тело: {username, email, password}

Profile Management

POST /get-profile
Получить профиль текущего авторизованного пользователя.
Требует токен

PATCH /update-profile
Обновить данные профиля.
Требует токен, Тело: {username, email}

DELETE /delete-profile
Удалить профиль пользователя.
Требует токен

User Management

GET /get-all
Получить список всех пользователей (только публичные данные).

GET /get-one/{user_id}
Получить профиль конкретного пользователя по ID.
