Account Endpoints

Create Account

POST /accounts/
Создать новый счет. Только для администраторов.
Заголовок: user_id (admin), Тело: {owner_id, name, balance}

Get Accounts

GET /accounts/
Получить список всех счетов.

GET /accounts/{account_id}
Получить информацию о счете с транзакциями.

Update Account

PATCH /accounts/{account_id}
Обновить данные счета. Только для администраторов.
Заголовок: user_id (admin), Тело: {owner_id, name, balance}

Delete Account

DELETE /accounts/{account_id}
Удалить счет. Только для администраторов.
Заголовок: user_id (admin)
